Como usar este modulo

Sigue este orden para que cada declaracion quede clara, conciliada y lista para revisar antes de presentar.

1. Consolidar operacion Tomamos solicitudes, operadores, peso y cierres del periodo para armar una base unica.
2. Completar firmante Define quien firma, con que documento y si hace falta un apoderado o respaldo adicional.
3. Adjuntar expediente Sube contrato, formulario, poder y cualquier respaldo que vaya con la presentacion.
4. Marcar estado Deja el caso como borrador, listo para presentar, presentado u observado segun corresponda.
